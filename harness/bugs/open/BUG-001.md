# BUG-001: Cart coupon request does not match implemented discount API

**Bug ID:** BUG-001  
**Title:** Cart coupon request does not match implemented discount API  
**Severity:** High  
**Priority:** P1  
**Feature:** FEAT-003  
**Environment:** Static source review; runtime test NOT_EXECUTED  
**Preconditions:** A customer has an item in cart and enters a coupon.

**Steps to Reproduce:**
1. Apply any coupon in `/cart` and inspect the network request.
2. Compare it with the Next route handler registered in source.

**Expected:** A valid code returns the discount and an invalid code returns a controlled rejection.

**Actual:** Cart sends POST `/api/v1/payment/discount`; backend implements GET `/api/payment/discount`. Static contract mismatch; no runtime evidence.

**Reproducible:** UNKNOWN / REQUIRES VALIDATION (static route/method mismatch)

**Evidence:** [src/app/cart/page.tsx](../../../src/app/cart/page.tsx); [src/app/api/payment/discount/route.ts](../../../src/app/api/payment/discount/route.ts)

**Root Cause:** No runtime root cause confirmed; client/server URL and HTTP method differ.

**Fix:** Align client request URL/method/response type with the supported API; do not change production behavior as part of harness creation.

**Regression Test:** Add/execute TC-011 after fix.

**Status:** OPEN
