# BUG-004: Payment persistence mutation targets a missing route

**Bug ID:** BUG-004  
**Title:** Payment persistence mutation targets a missing route  
**Severity:** High  
**Priority:** P0  
**Feature:** FEAT-004  
**Environment:** Static route inventory; runtime test NOT_EXECUTED  
**Preconditions:** A test checkout reaches the payment persistence step.

**Steps to Reproduce:**
1. Inspect `createPayment` RTK Query URL.
2. List Next payment route handlers and compare methods/paths.

**Expected:** A verified payment can be persisted with provider IDs/status and linked to one order.

**Actual:** Client posts to `/api/payment/createPayment`; no matching route exists. `/api/payment/create` is the Razorpay-order handler, not a Payment model persistence handler.

**Reproducible:** UNKNOWN / REQUIRES VALIDATION (missing route in tracked source)

**Evidence:** [src/redux/api/paymentAPI.ts](../../../src/redux/api/paymentAPI.ts); [src/app/api/payment](../../../src/app/api/payment); [src/models/payment.ts](../../../src/models/payment.ts)

**Root Cause:** Payment create route/handler is absent from tracked API tree; no external route was found.

**Fix:** Implement and document an authenticated/idempotent persistence contract as a product change; harness did not modify app code.

**Regression Test:** TC-012; include successful and duplicate callback regression cases.

**Status:** OPEN
