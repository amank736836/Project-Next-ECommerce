# BUG-006: Unauthenticated debug API returns a user record and mutates cache

**Bug ID:** BUG-006  
**Title:** Unauthenticated debug API returns a user record and mutates cache  
**Severity:** Critical  
**Priority:** P0  
**Feature:** FEAT-002 / cross-cutting security  
**Environment:** Static source review; endpoint was NOT called  
**Preconditions:** An attacker can reach the deployment and database/cache connections are configured.

**Steps to Reproduce:**
1. Send unauthenticated GET to `/api/admin-fix-v3` in an isolated authorized environment.
2. Inspect response for personal profile data and confirm cache side effect.

**Expected:** No public debug endpoint exists; user information and cache operations require least-privilege authorization.

**Actual:** Route has no auth check, deletes a cache key for a hard-coded user and includes the DB user document in JSON response. Static security finding; runtime access not attempted.

**Reproducible:** UNKNOWN / REQUIRES VALIDATION (source confirms no handler-level authorization)

**Evidence:** [src/app/api/admin-fix-v3/route.ts](../../../src/app/api/admin-fix-v3/route.ts)

**Root Cause:** Debug/troubleshooting handler remains in the public API tree without an authorization guard.

**Fix:** Remove/disable endpoint or apply a strict authenticated, audited, least-privilege support operation; review exposed data. Not changed by this task.

**Regression Test:** TC-027; add unauthenticated-route regression test.

**Status:** OPEN
