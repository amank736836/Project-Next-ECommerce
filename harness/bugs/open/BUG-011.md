# BUG-011: Dependency audit reports critical and high advisories

**Bug ID:** BUG-011  
**Title:** Dependency audit reports critical and high advisories  
**Severity:** High  
**Priority:** P0  
**Feature:** Toolchain / supply chain  
**Environment:** Executed `npm audit --json` in RUN-20261007-01  
**Preconditions:** Lockfile installed and npm registry audit available.

**Steps to Reproduce:**
1. Run `npm audit --json` against the lockfile.
2. Triage direct/transitive findings and fixes in a maintenance change.

**Expected:** No unresolved critical/high advisory under an owner-approved policy; exceptions are documented.

**Actual:** 29 advisories: 3 critical, 19 high, 6 moderate, 1 low. Direct affected packages include Next, Axios, Mongoose and eslint-config-next; full details are time-sensitive.

**Reproducible:** YES (audit reproduced on 2026-10-07; advisory set can change)

**Evidence:** [reports/dependency-audit.md](../../reports/dependency-audit.md); [evidence/logs/RUN-20261007-01-audit.log](../../evidence/logs/RUN-20261007-01-audit.log)

**Root Cause:** Dependency versions in lockfile match ranges flagged by npm audit at run time.

**Fix:** Review advisory impact and compatible fixes, update dependency lockfile in an application maintenance change, rerun build/lint/audit. No dependencies changed here.

**Regression Test:** TC-031.

**Status:** OPEN
