# BUG-014: Coupon generator metadata is discarded by API handlers

**Bug ID:** BUG-014  
**Title:** Coupon prefix/length/character settings are not persisted  
**Severity:** Medium  
**Priority:** P2  
**Feature:** FEAT-007  
**Environment:** Static source review; runtime test NOT_EXECUTED  
**Preconditions:** Admin creates or edits a coupon using generator controls for size, prefix, postfix and character sets.

**Steps to Reproduce:**
1. Configure non-default coupon size, prefix/postfix and character-set flags in the admin UI.
2. Create or update the coupon in an isolated test environment.
3. Reload the coupon record and compare stored fields with submitted form state.

**Expected:** Fields represented in the coupon model and admin UI persist consistently if they are intended product settings.

**Actual:** Client mutation sends these fields, and the Coupon model defines them, but `POST /api/payment/coupon/new` destructures only `code` and `amount`; `PUT /api/payment/coupon/[id]` updates only those fields. Model defaults therefore remain for generator metadata. This is a static contract discrepancy; no runtime admin test was performed.

**Reproducible:** UNKNOWN / REQUIRES VALIDATION (source comparison; runtime was not exercised)

**Evidence:** [New coupon UI](../../../src/app/admin/coupon/new/page.tsx); [coupon client mutation](../../../src/redux/api/paymentAPI.ts); [create route](../../../src/app/api/payment/coupon/new/route.ts); [update route](../../../src/app/api/payment/coupon/%5Bid%5D/route.ts); [Coupon model](../../../src/models/coupon.ts)

**Root Cause:** API handlers ignore metadata fields included by the UI and modeled in MongoDB.

**Fix:** Confirm whether metadata must be persisted; if so, align API validation and create/update behavior. No application code was changed in this harness task.

**Regression Test:** TC-022.

**Status:** OPEN
