# Test Evidence

Only genuine evidence from an actual run belongs here. Current evidence consists of command logs under [`logs/`](logs/); no screenshots, videos, API response captures, database query outputs, or performance traces were produced.

Use subfolders only when evidence exists. Redact credentials, tokens, personal data, and sensitive provider IDs before storing evidence. Link each artifact from the test case and `RUN-...` execution record. Do not create or present fabricated screenshots/logs.
