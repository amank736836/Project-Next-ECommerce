# Reports

- [Test summary](test-summary.md): latest execution counts and observations.
- [Coverage](coverage.md): feature/requirement/scenario/case/API/UI/database/automation coverage, with unknowns clearly separated.
- [Traceability](traceability.md): REQ → FEAT → SCN → TC → automation → RUN → evidence mapping.
- [Regression report](regression-report.md): regression inventory and execution status.
- [Release readiness](release-readiness.md): evidence-based release recommendation.
- [Dependency audit](dependency-audit.md): actual npm audit result for the inspected lockfile.

Execution detail and raw logs are in `test-results/latest/` and `evidence/logs/`. Do not infer a pass from an empty result/evidence directory.
