# Test Results

Only actual executions belong here. Use a stable ID such as `RUN-20261007-01` and preserve the commit, tool versions, environment and exact commands. Store the newest record in `latest/`; place later completed runs under `historical/`; keep concise cross-run summaries in `summaries/`.

Also record command exit codes, prerequisite gaps, and whether failures are application tests, static quality checks, or security audit findings. Do not claim a test passed because build succeeds or a test case exists. Keep credentials and personal data out of logs.
